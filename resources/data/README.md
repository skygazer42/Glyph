## 来源、解析与运行副本

- **采集原件**保存在 `raw/`，保留文件字节、来源及已有指纹。
- **解析结果**保存在 `process/`，由 `policy_catalog/` 记录原件、正文、来源 URL、适用地区和核验结果的对应关系。当前服务范围见[政策资料目录](policy_catalog/README.md)。
- **应用上传与解析缓存**继续位于项目 `uploads/`，这是网页工作区的运行副本；不替代这里的原始资料归档。
- **FAQ 运行文件**继续位于 `resources/faq/`；本次逐文件复制到 `exports/faq/20261121/` 留存，快照与复制时的运行文件哈希一致。
- **历史隔离资料**保留在 `resources/archive/`，用于追溯之前的资料版本，不混入当前默认政策集。

没有为集中归档更改原文路径、规则来源哈希、文档 ID、数据库记录或向量索引。现有脚本与配置仍使用原有运行位置，入口说明见[项目结构](../../docs/PROJECT_STRUCTURE.md)。
