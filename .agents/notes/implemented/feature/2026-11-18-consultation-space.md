# 公众咨询冷启动与流体管理工作区

Status: implemented

## Problem

用户指出空咨询标题与吸底输入形成大段中间空白，空依据栏默认展开又使舞台偏向一侧；管理页的阅读型限宽与卡片内容高度没有利用工作区。

## Decision

管理页使用1680px流体上限及父容器剩余高度。宽屏规则原文/YAML同屏，窄屏保持原有Tabs，模型和请求仍由父页面管理。加载只替换未取得数据的空内容为骨架，已有数据保留。

咨询保持同一个输入和FileUploader实例，DOM顺序是欢迎标题、输入、推荐。空态用可滚动Flex及自动外边距聚拢，有消息时恢复消息区滚动/输入吸底；不复制一套冷启动表单，也不以负空间居中裁切短屏。公众咨询动作提为展示组件，以便桌面单层顶栏与后台标题栏共用。

默认收起空依据，桌面真实来源/条件且处理结束后才自动展开；用户关闭在当前咨询中优先。手机保留手动入口，避免异步答复抢占输入焦点。测算沿用原表单，不同时强行打开手机依据模态层。切换与成功清空咨询重置依据；切换时统一中止旧附件上传，避免附件跨会话。

## Alternatives considered

- 两套输入框分别用于空态/问答：容易分裂上传、IME、取消和草稿状态，因此只调整现有实例的位置。
- 每次收到任意答复都打开依据：无引用也会展开空栏，且会覆盖用户关闭选择，因此按真实引用与用户意图判断。
- 嵌套min-height:100dvh：外壳已占有视口，重复计算造成纵向溢出，因此使用父容器高度。
