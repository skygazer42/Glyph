# 暗色图谱的视觉聚合与真实数据

Status: implemented

用户要求解决四类语义映射、中心边噪声与亮角标。R22允许使用名称补全泛化类型，因此更新了R20“只按type”的显示决定；明确类型仍优先，原始字段未改变。

视觉边按端点/方向分组，仅画布总览聚合；成员仍引用原始边，聚焦时展开关联组。按原始ID保留实体，不能把名称相近直接当作同义机构。总关系计数来自raw links，节点面积与+N分别取全图唯一邻居数及其未显示部分。

没有复制示例的bundle模式来冒充合并：bundle只负责展开后的平行弧线，聚合由纯数据展示函数负责。未知英文关系键不露在画布，原值在可展开详情保留，中文映射只改变阅读标签。

避免每次hover重跑力布局，只替换视觉边并保留节点位置。主题和尺寸变化保持世界中心/缩放，旧实例的异步失败不得覆盖新图。最小回归源码已补但未执行；来源与视觉证据边界见docs/frontend-audit/graph-dark-r22.md。
