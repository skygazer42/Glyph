# 常州公积金金额准确性独立审计

核对时点：2026-11-21。只读实现、规则和既有资料，仅新增独立回归测试。范围为七条 Provident 规则，并旁查已有装修和物业费规则（同属公积金提取）。困难家庭贷款贴息新政策由主代理另行研究，不与补充缴存利息补贴混同。

## 结论

本轮未发现已证实的高严重度金额公式错误。新增35项独立回归测试通过，Ruff通过。测试不是调用实现内公式助手产生期望值，采用公开金额档位、独立年金公式、等额本金闭式总利息与官方每万元还款表交叉核验。

## 限制与后续注意

1. 贷款规则把资格、支持对象、真实材料及历史记录集中在显式资格核实字段，属于带前提的金额估算，不能宣称独立完成资格审批。人员60月平均余额、租房还原及共济额度仍须中心核定。
2. 月供和总利息与官方参考表总额可能有分位差异。官方表自身说明仅供参考、以合同为准；实现披露逐期舍入及末期调整，未把估算舍入宣称官方统一规范。
3. 净余额字段必须扣应保留余额，并满足材料时点。一般资格=true不能替代实际产权/交易/收入核验；对未知应返回人工核验。
4. 未从“页面有效”推导所有历史金额仍有效，按后续正式政策条款优先。未重复研究主代理负责的困难家庭贷款贴息。
