当前23条活跃规则：保留8条，新增15条。21条支持在各自适用期及明确事实下试算金额；2条仅显示需核验事项和政策上限，不输出成功金额。完整逐条清单位于`resources/data/policy_catalog/FINANCIAL_RULES_20261121.md`。

## 覆盖范围

| 方向 | 金额内容 |
| --- | --- |
| 新能源/燃油汽车 | 常州执行的报废更新、置换更新金额；新能源乘用车购置税正常税额、减税额、实际应缴额 |
| 住房 | 工薪新房/存量房购房资助、装修和物业费公积金提取 |
| 公积金缴存 | 2026结算年度基数上下限、双方同比例、分别见分进元、单位及个人月额 |
| 公积金贷款 | 60/30倍正常月均余额、补充和异地6倍、亲属共济、普通80/120万与人才/多孩支持、高品质50万和绿色30万叠加；同时受房价、首付、收入及期限约束 |
| 公积金还款 | 等额本息/等额本金首末期、总利息、本息总额；一年期到期还本付息 |
| 其他公积金金额 | 租房/购房可提净额、补充及灵活就业缴存结息补贴50%且结算年度5000元上限 |
| 育儿/就业 | 单个儿童2026归属年度标准及过渡出生年份折月金额；困难毕业生一次性求职补贴及明确申报窗口 |

购置税结果是应缴税款，公积金贷款结果是本金，缴存结果是单位加个人入账额，购房资助是购房款抵扣；均明确性质，不混为普发现金。人才公积金贷款支持已可按条款计算。

## 两项不能伪造的现行金额

人才生活/房票原文仅给出最高1600元/月、30万元人才房票；尚缺可核的现行学历档位、期间与旧政策衔接细则。现有入口转人工，不将最高额当个人应得额，不套2021旧版金额。

电动自行车收录的2026官方问答没有明确本期金额和期限。现有入口转人工，不套2025年30%/1000元。已结束的常州纯购新车活动未被做成现行现金规则。求职补贴按2026年9月及2027年5月规定申报期开放，当前不在申报期不会返回成功金额。

## 改动与简化

- 新增3个纯计算模块：`app/agents/dsl_generator/{provident_fund_calculations,changzhou_vehicle_calculations,changzhou_benefit_calculations}.py`及15个`rules/Rule_Changzhou_*_2026.yaml`。
- `rule_engine.py`仅注册显式允许的金融helper，保留原表达式安全边界。各新规则的来源、有效期、中文字段和示例均可回读。
- `rule_agent.py`向模型提供真实枚举选项；缺项仍可匹配业务再由引擎中文追问；保留金额小数和官方URL，人工/过期/不符状态不说“可领0元”。
- `rewrite_agent.py`将能效/产品槽位限定家电，避免公积金问题被追加家电缺项。服务与路由提示补齐工资、贷款、月供利息和税款线索；补足“月缴存”等自然问法别名，避免前5候选漏掉实际规则。
- `agentchat_router.py`、`agentchat_team.py`的流返回协议与实际async generator一致；本地文件批迭代器类型一致。既有runtime测试夹具补齐缺失的`PolicyDomainContext`导入stub，未删除或放宽断言。
- 前端`web/src/views/DSLGenerator.vue`仅增加`NOT_IN_PERIOD`中文状态，复用现有输入、类型绑定和computed。写法规约证据位于`docs/plans/changzhou-finance-frontend-evidence.json`。
- 3份金额来源目录和3份FAQ目录接入既有统一导入；同URL/同正文可有不同保存路径，逐个验证实际正文哈希，保留原canonical版本。来源缺失issuer已按真实发布者补齐。

新增26个不同URL的官方来源后，当前181份官方资料（常州/江苏61、全国120）、173条FAQ、496条向量。保留的374条全国向量逐字段和嵌入坐标不变；界面182份文件包括原1份无关数学上传。采集中断产生的单个无引用上传及缓存已按SHA-256归档，未删除用户资料。

- 723项核心金额、跨层、预览、原规则及来源/FAQ回归通过。
- 25项服务/工具/流式/批处理回归、7项既有改写回归通过。

- 前端生产构建和写法规约代码绑定核验通过，保留既有大chunk提示。
- 真实鉴权接口逐条执行23个保存示例，并与草稿预览结果比对；两个人工入口保持MANUAL_REVIEW和零占位值，不被当成成功测算。资料列表、向量检索、FAQ和新地区税务FAQ均通过。

## 保留边界

不连接实时税务资格、房源库、社保、学籍、银行授信、预算额度或个人账户。必须由用户明确提供或核实相应事实，金额试算不等于审批或实际发放。贷款按公布利率不变并说明逐期分位舍入，银行合同、后续调息及真实还款计划优先。

SQL政策库仍未配置，本轮未建表、未声称SQL入库；新增金额资料已完成向量及FAQ接入。图谱保持上一轮10份完整住房资料和30份服务摘录的范围，未将本轮金融来源全部重建入图谱，也不使用图谱模型心算金额。没有新增依赖、自动提交或重置其他工作。
