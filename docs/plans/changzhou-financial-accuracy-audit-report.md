# 常州金额信息准确性校对结果

> 本文为上一轮24条规则的核验快照；后续常州官网追加核验、新增8份来源和第25条规则见[官网追加核验报告](changzhou-official-followup-report.md)。

核对时点：2026-11-21。范围为上一轮23条活跃金额/人工核验规则、对应官方原文与FAQ、常州住房政策，以及实际金额对话和检索接入；本轮补齐1条困难家庭贷款贴息，共24条。不是对所有政务事项的穷尽收录或永久有效性认证。

## 发现并处理的问题

1. **漏收现行贷款贴息。** 常公积金委〔2026〕3号自2026-07-01至2031-06-30实施，对上年度经本市民政/总工会认定的困难家庭，按该笔本市公积金贷款上年度实际支付的合规利息100%或80%贴息，贴息时不得逾期，同年度按就高原则不重复。原单笔每年6000元上限已取消。新增纯计算函数、规则、2份正式办法/官方解读、6条带原文引证FAQ，并已导入回读。官方案例2025年度利息12000元、低保边缘80%，在2026办理时试算9600元。它与既有50%且结算年度5000元上限的补充缴存/灵活就业缴存结息补贴分开。
2. **金额规则候选漏匹配。** 实际对话中的“公积金贷款年度贴息”和“困难家庭贷款贴息”原来不能进入前5候选，模型因而否认存在对应规则。补充真实业务别名，3个自然问法回归锁定正确候选；再次真实对话得到9600元。
3. **缺资格时可能进入知识总结。** “能领多少”即使被模型标为普通政策咨询，现在仍按当前问题的金额问法和金融主题进入规则追问。缺少困难类型、认定年度等事实，实际返回INVALID_INPUT及中文缺项，没有成功金额。金额意图以当前原问判断，避免改写丢词或历史金额问法污染本轮材料追问。
4. **材料查询误走不完整图谱。** 原“材料/怎么办理”单词足以触发图谱，新增贴息不在图谱中，曾实测得到普通贷款材料和错误的自行申请说法。删除该过宽匹配；关系、职责和跨部门流程联动仍可用图谱，单事项材料和步骤查询改走官方原文知识检索。
5. **知识总结混用业务材料。** 原统一家电式模板曾将电梯、报建等其他公积金提取材料拼入贴息答复。总结要求改为按具体政策、业务和年度隔离证据，非申即享不搬入其他事项材料，不强套能效/旧机格式。金融问题不再使用与问题无关的首篇正则抽取快捷返回。实际材料对话已返回非申即享，未再出现电梯、报建、分摊协议等无关清单。
6. **未生效日期说成过期。** 规则引擎原来对生效前和截止后统一提示“政策已过期”，现在提示“业务日期不在所选规则的适用期内”；对话也不再将历史业务日期误说成政策当前失效，保留已有EXPIRED接口状态兼容。
7. **交付数量过时。** 上一轮181份是历史快照；此前已导入的8份保险补充资料与本次2份贴息资料均重新回读。当前为191份官方资料、179条FAQ、507条向量、24条规则。目录中的未设置截止日改为“原文未载截止日”，不显示None。

贷款贴息依据：[正式办法](https://www.changzhou.gov.cn/gi_news/114178280753699)、[官方解读与9600元案例](https://www.changzhou.gov.cn/ns_news/421178280962476)。

## 既有规则校对

- 车辆、全国消费补贴、育儿和求职、人才及电动自行车入口：两条常州车补加四条全国规则的比例/封顶/互斥，购置税含税口径，出生年份折月、求职申报期等已逐规则复核，未发现新的实质金额错误。独立结果见[车辆与补贴审计](changzhou-benefit-vehicle-accuracy-audit.md)，新增67项独立预期测试。
- 公积金七条既有规则：缴存上下限、逐方见分进元，余额倍数、人才多孩互斥、绿色和高品质住房叠加、收入和首付约束、两种还款利率及总利息、租房购房提取余限等已复核。独立结果见[公积金审计](changzhou-provident-accuracy-audit.md)，新增35项独立预期测试；新贷款贴息亦经同一审计者独立追加复核。
- 新房/存量房购房资助及装修/物业费提取：主代理重新在线读取正式公告及解读，核对15%/20万和18万、房源库与面积限制、仅抵扣购房款及后续归还，装修累计10万及权证时限、物业费每套年度3000及跨年发票分摊；原66项住房行为回归通过。
- 另重新在线读取8份保险补充来源，确认2026与2027保障/投保年度分开，2027未成年基础版150元与成年人158元、升级版258元，职工医保最低年限分2023-06-01前后参保，灵活就业年龄与退休答复分别按原文保留，不混作统一退休年龄政策。
- 公积金主题目录标为2026-03-23的贷款支持条目，实际成文2023-04-07，不能用目录重列日期把旧额度当2026新政。当前代码用后续正式政策的新额度，未误改回旧数值。

## 改动与简化

主要源码：

- `app/agents/dsl_generator/provident_fund_calculations.py`：复用既有Decimal、日期、布尔校验与结果结构，新增困难家庭年度贷款贴息函数。
- `app/agents/dsl_generator/rule_engine.py`、`app/agents/pipeline/rule_agent.py`：显式注册新函数，纠正适用期提示。
- `app/agents/service/agent_service.py`：个人金额问题的确定性路由；删去单个材料/步骤关键词就触发图谱的过宽分支和重复判断。
- `app/agents/pipeline/knowledge_agent.py`：按问题、业务和年度使用证据，金融事项绕过无问题约束的快速摘录，去掉统一家电式回答模板。
- `scripts/official_policy_data.py`：新来源和FAQ接入同一导入链。

规则与资料：`rules/Rule_Changzhou_ProvidentHardshipSubsidy_2026.yaml`，`resources/data/{raw,process}/changzhou_financial_accuracy_20261121/`，对应catalog和FAQ；主FAQ与规则manifest及清单已同步。

测试：新增3个准确性审计测试文件；扩大回归暴露的两处旧夹具补齐真实协议（async rewrite、假Milvus字段维度），保留原断言。Ruff另发现runtime测试4个未用绑定，保留模块加载副作用并移除绑定/无效查询。未为通过测试修改实际凭据、真实集合维度或数据库。

没有新增依赖或自动提交；前端本轮无改动。

## 仍需核验的事项

- **人才生活/租房补贴和专属房票**：现行正式措施有最高1600元/月、30万元，但缺完整可适用的学历档位、期限和废止衔接细则。继续人工核验，不将2021旧标准、2026年初新闻或最高额当个人可领额。人才公积金贷款支持是独立已实现规则。
- **电动自行车**：已收录的2026官方问答未给本期金额与活动期限。继续人工核验，不套2025年30%/1000元。
- 其他医保报销、养老金等复杂事项目前主要提供来源检索，未因此宣称已有自动金额审批或完整报销计算。
- 资格、账户、房源、认定、车辆状态、预算与实际发放不连接实时主管系统。试算不是审批；月供按明示固定利率与舍入估算，实际合同/调息/银行计划优先。
- 生成式知识总结仍可能遗漏信息，须保留官方出处并与原文核对；不能把这次测试通过说成对任何未来问法逐字正确的保证。
- 本次新资料进入向量及FAQ，未全量重建图谱；图谱仍为10份完整住房资料加30份服务资料摘录范围。SQL政策库仍未配置。此前用户97份原始资料保持归档状态，不因数量增加就宣称已经核验或导入。
