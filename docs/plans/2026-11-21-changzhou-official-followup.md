# 常州官网追加核验与补漏计划

用户要求继续去常州政府官方校验，延续钱相关资料准确性目标；只使用常州市政府及主管部门可打开的正文作为本轮新增政策依据，不把转载、检索摘要或咨询标题当正式规定。

1. 继续由两个既有代理只读核验：商务局车辆/电动自行车与新轮次；人社民政医保的新金额和漏项。主代理查人才细则、比对现有目录、保存证据并接入。
2. 先核正式文件、可见日期、施行期、主体、金额性质、限额和互斥；同一年旧FAQ不自动优先于较晚正式通告。对无法取得完整依据的档位继续保留人工核验。
3. 保存网页服务原始输出及规范化全文、哈希和新catalog，必要FAQ注明“最低标准/保障标准/最高额/实际补贴”的区别；沿用既有导入并回读，不新增依赖，不自动提交或回滚。
4. 对已有金额覆盖中的明确漏项按来源补规则；无法完整确定资格/期间/叠加时仅接入资料及问答，不能伪造自动计算。修改前先有实际反例或新行为测试。
5. 核对来源/FAQ/规则一致性、运行相关pytest和静态检查、实际接口/检索/对话验证；报告本轮新发现、当前数量及尚未找到完整依据的事项。
