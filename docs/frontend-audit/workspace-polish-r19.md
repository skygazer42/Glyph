原诊断的“检索页侧栏消失”未在同一桌面视口复现：两个标签共用 WorkspaceLayout；手机原本有底部导航。保留这一响应式区别，补显式桌面收起入口。原文涉及“数据产品策划”的另一套界面不属于此仓库。

常见问题继续填入草稿，补充后发送，避免一键提交已有草稿。登录、安全 Cookie、权限、资料处理与真实 API 均沿用原实现。共享阅读上限同时收敛解析正文行宽，不修改 PDF 原页。

实际查看 1440×900 与 390×844 的公众咨询、后台对话、检索、登录，以及侧栏折叠和阈值编辑状态。百分比编辑到 65 后滑块显示 0.65；恢复 50 时滑块同步。未提交咨询、检索或资料操作，不把后端 503 当作业务成功。
