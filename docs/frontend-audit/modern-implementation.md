## 原型到工程对照

| 原型内容 | 项目既有能力 | 实施方式 |
| --- | --- | --- |
| 白色品牌栏、横向导航 | WorkspaceLayout、Vue Router、GlyphMark | 现成的加一个变体，统一替换后台外壳 |
| 蓝/白/灰、微软雅黑15/24与阅读18/32 | variables.css 与 --wb-* | 用现成的，调整共享角色值 |
| 资料筛选、宽表格、导入 | Element Plus、KnowledgeBase、KnowledgeImportDialog | 用现成的，按02重排 |
| 原文、解析、切块、处理方案 | KnowledgeDocumentWorkspace、knowledgeApi | 用现成的，保留版本核对和失败输入 |
| 图谱与实体说明 | ECharts、GraphML API、既有图数据规范化 | 现成的加一个变体，选中状态局部管理 |
| 原文—规则—测试 | DSLGenerator、CodeEditor、dslApi | 用现成的，不新增工作流接口 |
| 两种咨询展示 | AgentChat、SessionManager、FileUploader、PolicyEvidence | 现成的加一个workspace展示属性，共用数据流 |

没有新增组件库或业务依赖。生产页面不读取 .oil-ui，不嵌入HTML原型，不携带原型政策样本。静态设计预览和浏览器隔离验证资料均保留在本任务工作区。
