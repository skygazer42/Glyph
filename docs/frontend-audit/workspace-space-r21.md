# R21 视口与冷启动空间

沿用资源工作台、经纬标记和青蓝品牌，按用户本轮文档修改管理页空间与公众咨询。没有更换后端、增加固定政策样本或伪造连接成功。

| 编号 | 用户意见 | 本轮实现 |
| --- | --- | --- |
| 1 | 管理页两侧留白、底部悬空 | 管理容器100%流体宽、1680px上限、28px横向/20px纵向边距；列表吸收父工作区剩余高度，不重复计算外壳视口高度 |
| 2 | 检索两栏底部错位 | 条件/结果Grid stretch等高，嵌套Tabs获得剩余空间，手机继续单列滚动 |
| 3 | 空会话标题和输入首尾分离 | 原有单个输入框、附件组件保留，DOM按标题→输入→推荐排列；零消息聚拢居中，有消息恢复滚动流与吸底 |
| 4 | 多重顶栏与空依据占位 | 公众端56px单层全宽页头，手机在同一页头内换行；依据默认收起，桌面真实引用到达后按需展开，主动关闭不被下一次响应强行打开 |
| 5 | 断连横幅中间空洞 | 内容自适应紧凑提示，文字与重连靠近；仍检查真实health响应，不用点击动作伪造恢复 |
| 6 | 提示条、禁用控件和侧栏重复 | 原文提示进入placeholder；资料标题/筛选合并单层；两种禁用控件同色；移除侧栏静态政策资料区 |
| 7 | 宽屏闲置与加载重影 | >=1536原文/YAML/试算三栏同屏，窄屏保留Element Plus Tabs；规则初读用三行骨架，刷新按钮不转圈，已加载行刷新时保留 |

宽屏同屏对照是在用户给出的双栏加宽/三栏两种建议中选择后者，仅应用于足够宽的视口，不复制生成、保存或试算业务逻辑。标题、原文和YAML仍绑定父级状态。

当前会话的手动依据选择独立于来源数据。自动展开仅在桌面、生成结束、有真实引用/条件且没有被用户主动关闭时触发；手机继续以引用入口手动打开，测算保留原有表单，避免堆叠两个模态层。

源码独立复核发现历史切换可能继续携带旧附件、清空后可能保留空依据栏。已在loadSession统一清理并中止上传，成功clearChat统一收起依据；上传成功回调仍由原pending集合拒绝迟到结果。

按用户要求未执行测试、lint、构建或专门编译检查。新增依据自动展开条件回归源码未运行。资料、模型及完整规则服务仍未启动，画面保留真实断连/失败，不通过样本填补空白。

画面证据在 `.oil-ui/workspace-space-r21/shots/`：1920×1080宽屏、1440×900桌面、390×844手机。修改前公众宽屏在本轮捕获，其余对照沿用R19/R20相同视口截图，不伪造历史宽屏版本。

独立视觉评审未发现确定阻断或规范偏离；仅建议缩短手机欢迎说明末行，已去掉非必要的“购买”二字。真实页面查看了桌面依据开/合与多视口，生成、引用自动到达、附件切换等业务路径没有运行，源码评审不能替代这些联调。
