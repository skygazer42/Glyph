# 写法专项复核计划

本轮以用户最新要求为准：代码写法为主，必要的边界防御为辅。范围仍是 web 下全部 37 个维护文件；沿用已选 Vue 3、JavaScript、Element Plus、scoped CSS、2 空格、单引号、JS 无分号的项目合同，不新增依赖。

1. 保存当前产品字节与报告快照，按基础层、组件、页面三个互斥分区逐文件复核。只复用现有两个子智能体，不派生更多智能体。
2. 重点检查 const/let 与声明范围、命名与导入、对象和解构、明确的数量/字符串条件、完整控制块、简单三元与清晰函数职责。保留真实公开签名及既有具名函数/箭头风格，不机械更换函数形式或提取新层。
3. 检查所有 Vue 模板的属性命名、多属性换行和表达式复杂度；检查全部 CSS 的作用域、语义类名、选择器与声明排版。不新增业务交互或改变视觉样式。
4. 在真实输入边界保留已有必要校验与清理；不扩展未知输入假设、不添加多层兜底、通用 helper 或新的防御框架。只删除确无职责的冗余。
5. 纯写法调整优先保持 AST、模板合同及 CSS 值一致；行为已有 62 项回归保护，本轮不为机械排版新增测试。每个改法需指向适用规则和固定原文；新增/改名声明另作逐项命名记录。
6. 集成时根据实际内容迁移最终代码证据，验证每一段仍支持其叙述。重新运行现有回归、包内 check、生产构建和来源/代码绑定核验。交付以写法变化及保留取舍为主，工具通过不代替人工写法判断。

完成标准：37 文件均有本轮写法结论；已发现的适用写法差异全部修正，或以明确项目合同记录合理保留；无新增依赖、无额外防御工程、既有测试通过，最终证据对应交付源码。
