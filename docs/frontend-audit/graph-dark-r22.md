# R22 暗色图谱阅读与层级

用户本轮提供了类型、边密度、标签、角标和底部HUD五类反馈。沿用G6 v5、全工作区画布、经纬Logo与现有认证，不更改GraphML文件或机构身份。

| 编号 | 意见 | 本轮实现 |
| --- | --- | --- |
| 1 | 政策与材料全进绿色兜底 | 明确类型优先；泛化document/content等按细则/方案/公告/通知、发票/行驶证/消费者等名称补显示分类；网站/地区不据机构名称误判。原始类型和名称保留 |
| 2 | 枢纽等大、角标抢眼 | 按API neighbor_count唯一关联实体数分22/32/44直径；只保留未显示邻居的+N；暗色角标改灰底细描边，鸟瞰隐藏微小角标；核心使用低透明微光 |
| 3 | 高密度交叉与斜向英文 | 概览按端点与方向聚合视觉边，聚焦相关组才展开，保留所有members；概览无语义边文字，悬停/选中显示水平中文关系，未知键通用中文显示、原值在详情折叠核对 |
| 4 | 长标签被连线穿透 | 画布单行Unicode截断，节点和边都有主题底衬；鼠标浮层用textContent显示完整名称，不注入原始HTML；一跳聚光灯与G6标签避让共用 |
| 5 | HUD上下割裂与白色选中态 | 概览/实体与原始关系数/图例合成一个底部悬浮岛；控件同样留边，手机岛内换行；层级选中改半透明深青蓝 |

原文的145关系未写入界面。仓库当前桌面概览实际是24实体/47原始关系，全库185实体；手机12实体/17关系；从搜索定位济南市商务局时为29实体/39关系，均来自真实API。原始关系计数不会因画布聚合而变少。

节点大小使用全图唯一邻接实体数，不重复累加同一对实体的平行边；角标是该值扣除当前已展示的唯一邻居数。两者与“原始关系条数”分开，以免平行边把权重虚增。名称相近的“市商务局/济南市商务局”没有自动认定同一实体，后续需有确认的别名映射才能归并。

使用现有包内d3-force有界迭代，降低向心约束、提高排斥和边距；宽画布向横向舒展，窄画布按纵向约束，为搜索及底部岛预留安全区。没有加入任何按政策名称定位的固定坐标，也不承诺固定性能或面积占比。

源码自检修正尺寸变化的隐式fitView（G6未溢出仍会居中），改为保持旧世界中心、用户手动适应才重置；主题重建保留节点位置和视野；旧实例的失败回调只可影响所属实例。原关系数组、权重、方向、自环与源版本仍保留。

## 证据边界

真实浏览器查看1440×900暗色概览、悬停、选中与390×844手机；浅色选中用于确认样式兼容。源码新增类型/字典/尺寸/聚合/方向/自环/零权重/成员保留回归，按用户要求未执行测试、lint、构建或专门编译检查。实际数据没有为展示平行聚合而添加样本，复杂平行边与高速交互边界尚未做运行回归。

图片在 `.oil-ui/graph-dark-r22/shots/`。比较基线沿用R20的有效同视口暗色图（同一GraphML与核心实体范围）；未使用本轮模块迁移期间产生的中间画面作为旧版成果。

独立视觉评审未发现阻断或明显规范偏离；建议选中态下缘避让HUD。已将搜索后的首次布局改为在详情栏展开、画布尺寸确定后执行适应，最终标签留在浮岛上方，主Agent看图确认；没有追加多轮评分。复杂平行关系仍只有未执行的回归源码及源码检查，未以额外样本冒充真实图谱效果。
