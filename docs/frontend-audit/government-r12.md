## 核验来源与判断

- [政府网站发展指引](https://www.gov.cn/zhengce/content/2017-06/08/content_5200760.htm)：直接访问官方页面核验了网站展现部分。它要求一致的色彩、字体、字号、行距和模板，以及合理层级、兼容性和可用性；该文没有指定Vue、React或Element。
- [浙江政务服务网](https://www.zjzwfw.gov.cn/)：实际浏览并保存1440×900参考图。借鉴身份识别、主任务和中文信息组织，不复制机关身份、地方事项或横幅。
- [Ant Design设计文档](https://ant.design/docs/spec/introduce-cn)与[GOV.UK Design System](https://design-system.service.gov.uk/)：区分企业设计体系、政府维护的设计系统与工程组件库；不把它们称作国内政府项目指定框架。

网站规范、项目技术约定和视觉质量是不同问题。公众网站的指引也不是内部后台的完整验收清单；本轮没有执行等保、信创、招标约定或完整无障碍验收。检索工具不可用时，来源改用官方网页直接访问核验。

## 实现

| 页面或共享区域 | 结果 |
| --- | --- |
| 全局外壳 | 64px蓝色品牌栏、208px白色业务侧栏、连续内容区；手机改为底部四个业务入口，保留安全区。 |
| 知识库 | 标签、筛选和资料列表合为连续面板，正文色文件名、独立正文/入库状态、靠近对象的行操作。DOCX等短格式不拆行。 |
| 文档处理 | 保留原文、解析、切块、方案四个视图。正文18px，280px处理侧栏；字符单位明确，解析方式有可理解的标签。 |
| 图谱 | 保留确定布局、搜索、邻域、平移缩放及真实详情，改进节点尺寸、字尾断行和关系文字对比。大图允许探索，不承诺手机一屏读清全部实体。 |
| 规则 | 原文、YAML和测试并列，编辑列按自身内容对齐顶部，生成/保存不被测试结果推离首屏。保存门槛和结果失效合同保留。 |
| 公众咨询 | 独立服务页头、1000px阅读上限、18px主要说明与答复；手机主要阅读17px。问题、历史提示、答复与来源分层。 |
| 后台问答 | 复用对话请求与存储实现，使用统一后台外壳；后台17px答复，保留数据库设置和原有工具。仅显示后端提供的可读路由标签，不回退展示原始内部枚举。 |
| 知识检索 | 参数与真实返回片段分区，保留有限摘要、展开、来源核对及返回上下文。隔离接口返回公文开头，不能据此证明真实检索效果。 |

功能、API、SSE、会话、附件、引用、文档版本/CAS、解析入库、规则生成保存测试均沿用。生产源码不引用过程目录或隔离服务。动效只保留交互状态、流式输出和既有过渡，没有新增装饰动画。
